# 🐍 Python Practice Programs

This repository contains a collection of beginner to intermediate Python programs that cover a variety of fundamental programming concepts. Each file demonstrates how to implement common logic and algorithms in Python — perfect for students, self-learners, and interview prep!

---

## 📂 Programs Included

| Filename                          | Description                                      |
|----------------------------------|--------------------------------------------------|
| `LCM.py`                         | Calculates the Least Common Multiple             |
| `Largest_smallest_average_in_array.py` | Finds largest, smallest, and average in an array |
| `attendence.py`                  | Simulates a basic attendance system              |
| `bank_application.py`           | Simulates basic banking operations               |
| `calculator_in_array.py`         | Array-based calculator for arithmetic operations |
| `encoder.py`                     | Encodes text with a basic cipher logic           |
| `factorial.py`                   | Calculates the factorial of a number             |
| `fibonacci_series.py`            | Prints the Fibonacci series                      |
| `guessRandomNumber.py`           | Number guessing game using random module         |
| `leap_year.py`                   | Checks whether a given year is a leap year       |
| `linear_search.py`               | Performs a linear search in an array             |
| `prime_numbers.py`               | Checks for prime numbers within a range          |
| `simple_calculator.py`           | Performs basic arithmetic operations             |
| `sum_natural_no.py`              | Calculates the sum of natural numbers            |
| `swaping.py`                     | Swaps two numbers                                |
| `temperature.py`                 | Converts temperature between Celsius and Fahrenheit |
| `time_by_birthday.py`           | Displays time-related data based on birthday     |
| `vowels_or_con.py`              | Checks if a character is a vowel or consonant    |
